# 六开关打地鼠显示（初版）

当前版本：`v0.5.1`。完整功能变更与代码位置见 [CHANGELOG.md](CHANGELOG.md)。

这个初版程序会读取 Arduino Mega 2560 以 115200 波特率发送的六位状态，并显示一个可缩放的 2 列 × 3 行方格区。界面采用 Qt（PySide6），可在当前 macOS 和 Windows 上运行。

- 串口数据第 1～6 位依次对应：第 1 行左、右；第 2 行左、右；第 3 行左、右。
- 当前接线为 `COM → GND`、`NC → D2–D7`：未按下时为 `0`，按下/撞击导致 NC 断开时为 `1`；收到 `1` 时，相应方块变黑。
- 每次收到 `1` 后，黑色命中状态从最近一次 `1` 起最多保持 1 秒；持续发送 `1` 会以最新收到的 `1` 重新计算这 1 秒。
- 收到的数据必须恰好是六个以空格分开的 `0`/`1`。不完整或异常行会被忽略。

Arduino 输出示例：

```text
0 1 0 0 0 1
```

## macOS 运行

在终端进入本文件所在文件夹后运行：

```bash
python3 -m pip install -r requirements.txt
python3 mole_game.py
```

首次打开后点击“刷新”，选择 Arduino Mega 2560 实际枚举出的端口后点击“连接”。本程序不硬编码开发板端口。使用本程序时，请关闭 Arduino IDE 的串口监视器，因为同一时间只能由一个程序读取串口。

## Windows 运行

1. 安装 Python 3（安装界面请勾选 **Add Python to PATH**）。
2. 将项目中的 Python 文件和 `requirements.txt` 复制到同一文件夹。
3. 在该文件夹的命令提示符中运行：

```bat
py -m pip install -r requirements.txt
py mole_game.py
```

连接 Arduino 后点击“刷新”，在下拉列表选择正确的 `COM` 端口，再点击“连接”。若不确定端口，可在 Arduino IDE 的“工具 → 端口”中查看。

## 目前的开关逻辑

当前硬件使用 COM + NC：未按下时引脚为 `0`，按下时为 `1`。因此 Arduino Mega 2560 应以 115200 波特率发送“按下 = 1、松开 = 0”的数据，例如 D3 按下时：

```text
0 1 0 0 0 0
```

## 当前游戏流程

1. 初始界面提供“初始分数”和“胜利分数”下拉框，以及“开始游戏”按钮。初始分数以 10 分递增，可选 `10分`～`100分`，默认 `10分`；胜利分数以 10 分递增，可选 `30分`～`200分`，默认 `30分`。点击开始或按空格键后，游戏得分显示为所选的初始分数。
2. 开始后收到的第一个完整串口帧只作为每格的初始基准，不显示命中效果也不计分。游戏进行中，每个位置仅在该位从 `0` 变为 `1` 时加 `1` 分。Arduino 会持续发送状态行，因此同一个开关保持 `1` 不会重复加分；回到 `0` 后的下一次 `1` 才算新的命中。
3. 点击“结束游戏”或在游戏进行中按空格键后，分数隐藏、方格恢复白色，方格区域中央显示“游戏结束”。此后串口帧仍会被读取但不会触发黑色命中效果或改变分数；点击“开始游戏”或按空格键可重新开始。
4. 分数达到所选胜利分数时，中央显示“游戏胜利” 1 秒，随后回到初始界面；胜利提示期间按空格键可立即跳过等待并回到初始界面。
5. 开始前必须保证初始分数小于胜利分数，否则程序会提示并拒绝开始这一局。
6. 分数小于等于 `0分` 时，中央显示“游戏失败” 1 秒，期间不响应串口命中；失败提示期间按空格键会立即跳过等待并回到初始界面，与胜利提示的空格逻辑一致。当前尚无扣分规则，因此正常使用下不会触发失败条件。

## 不接开发板时的模拟测试

`serial_signal_simulator.py` 是独立的串口发送程序。启动后选择一个**发送端**串口并点击“开始模拟”，它会立刻发送一帧，之后每秒随机发送一帧：恰好一位为 `1`，其余五位为 `0`，格式与 Arduino 输出相同。相邻两帧的 `1` 不会落在同一位，保证每秒切换位置。

也可无界面运行（`--count 0` 表示持续发送，按 `Ctrl+C` 停止）：

```powershell
.\.venv\Scripts\python.exe .\serial_signal_simulator.py --headless --port COM10 --interval-ms 1000 --count 0
```

若要让 `mole_game.py` 读取模拟器的输出，Windows 上需要一对互连的虚拟串口（例如 `COM10` 与 `COM11`）：

1. 运行 `py serial_signal_simulator.py`，选择其中一个端口（如 `COM10`）作为发送端。
2. 运行 `py mole_game.py`，选择配对的另一个端口（如 `COM11`）并连接。

两个程序不能同时打开同一个 `COM` 端口；必须使用一对互连的虚拟串口，或两个由外部设备实际互连的串口。
